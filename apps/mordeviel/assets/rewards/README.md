# Pièces de Mordeviel

- `gold_moon.webp` : pièce Lune d’or fournie par Logan, utilisée dans la bourse, les profils, la boutique, les récompenses et la barre d’accueil.
- `bronze_moon.webp` : Lune bronze fournie par Logan. Visuel disponible via `CoinToken(metal: MoonMetal.bronze)`. Tous les comptes démarrent à zéro, visible dans le profil et la bourse ; les gains et paiements en bronze seront définis plus tard.

Les images ont seulement été redimensionnées et converties en WebP pour limiter le poids. Les marges et la silhouette sont masquées par le composant Flutter commun ; les illustrations fournies ne sont pas redessinées.
