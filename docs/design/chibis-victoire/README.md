# Chibis de victoire — Mordeviel

Collection de 20 PNG à fond transparent, créés un à un à partir de la direction visuelle du Villageois. Les Deux Sœurs partagent un fichier. Sulfuron est inclus comme personnage illustré.

Ouvrir `catalogue.html` pour consulter la collection. Les fichiers de ce dossier sont les originaux de conception ; les copies consommées par Flutter sont dans `apps/mordeviel/assets/chibis/victory/`.

La scène de victoire utilise les identifiants des vainqueurs, leurs rôles finaux révélés et `alive_ids`. Les survivants sont placés au premier plan, plus grands ; les alliés éliminés sont placés derrière, plus petits et atténués. Les perdants ne sont pas ajoutés. Les Deux Sœurs ne sont pas affichées deux fois. Une partie nulle conserve sa présentation sans groupe victorieux.

Les sources regardent généralement vers la droite : seul le rendu de l’image est retourné horizontalement pour les places à gauche de chaque rangée. Les noms ne sont jamais inversés. Le centre garde son orientation. Pour un groupe large, le bandeau défile horizontalement afin de préserver la lisibilité.

Les images sont statiques ; elles ne constituent pas encore des animations articulées. Aucun changement des règles de victoire n’est inclus.
